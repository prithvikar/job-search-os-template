# Evidence Ledger

The spine of the system. Every resume/outreach claim MUST trace to an entry here.
Composer selects from these; it never invents. Keep metrics exact and defensible.

```yaml
- id: vax-platform-01
  raw: "Owned roadmap for state vaccine distribution platform serving 4M residents"
  metrics: {scale: "4M residents", uptime: "99.9%", timeline: "8mo to GA"}
  domain_tags: [healthcare, HL7, public-sector, roadmap-ownership]
  evidence_strength: high
  verifiable_via: [linkedin, manager-reference, public-press]
  reuse_count: 0
  last_used: null

# Add entries below. evidence_strength: high = survives a reference/skills check.
```
